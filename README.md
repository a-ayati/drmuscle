# على قدّك

غذاؤك حسب ميزانيتك، وتمرينك حسب مستواك.

تطبيق ويب يفتح فيه كل شخص حسابه ببريده وكلمة مرور، وتُحفظ خطته (الأكل، المشتريات، التمارين، التقدّم) في حسابه، فيصل إليها من أي جهاز.

## كيف يعمل

- **الواجهة:** React وTailwind (مجلد `src`).
- **الخادم:** Cloudflare Worker (مجلد `worker`) مع قاعدة بيانات D1 تُنشأ تلقائياً عند أول نشر.
- **الحسابات:** بريد وكلمة مرور. كلمة المرور لا تُخزَّن كما هي، بل مشفّرة باتجاه واحد. لا يحتاج التطبيق أي خدمة خارجية ولا أي مفتاح.
- **الوضع الليلي:** من الإعدادات (فاتح، ليلي، حسب الجهاز). ألوانه في `src/dark.css`، ويُولَّد تلقائياً عند البناء من `scripts/gen-dark-css.mjs`.

## النشر على Cloudflare (مرة واحدة)

1. ادخل إلى Cloudflare، ثم **Workers & Pages** ← **Create** ← **Import a repository**.
2. اختر المستودع `a-ayati/drmuscle` والفرع `main`، واترك الإعدادات كما هي، ثم **Deploy**.
3. بعد دقيقة يصبح الرابط جاهزاً بالشكل: `https://drmuscle.<حسابك>.workers.dev`.

بعدها كل تعديل يُرفع إلى `main` يُنشر تلقائياً.

### إعدادات اختيارية (من صفحة الـ Worker ← Settings ← Variables and Secrets)

| الاسم | النوع | الفائدة |
|---|---|---|
| `ADMIN_EMAILS` | Text | بريدك، ليظهر لك وحدك زر «لوحة الإدارة». |
| `GEMINI_API_KEY` | Secret | يفعّل ردود Gemini في «كابتن على قدّك». بدونه يعمل الكابتن بردود جاهزة، ولا تُرسل أي بيانات خارج Cloudflare. |

## التشغيل على جهازك

```bash
npm install
npm run preview   # يبني الواجهة ويشغّل الخادم وقاعدة البيانات محلياً على http://localhost:8787
```
